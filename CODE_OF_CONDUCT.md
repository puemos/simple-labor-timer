# Code Of Conduct

Simple Labor Timer aims to be a respectful, practical project for people building and using a privacy-first labor timer.

## Expected Behavior

- Be respectful and constructive.
- Assume sensitive health and pregnancy contexts may be involved.
- Keep feedback specific, actionable, and focused on the work.
- Respect different experience levels, languages, cultures, and care settings.
- Avoid sharing private medical or personal information in public project spaces.

## Unacceptable Behavior

- Harassment, threats, insults, or sustained personal attacks.
- Sexualized language or imagery.
- Discriminatory comments related to age, body size, disability, ethnicity, gender identity, nationality, race, religion, sexual orientation, pregnancy status, or care choices.
- Publishing someone else's private information without explicit permission.
- Deliberately derailing issues or pull requests.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or block contributors whose behavior harms the project or its community.

If you need to report a conduct issue, open a maintainer-facing GitHub report if available. If only public issues are available, avoid personal details and ask for a private contact path.
